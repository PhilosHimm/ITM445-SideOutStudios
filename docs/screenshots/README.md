# Screenshots

The root README references three images from this folder. They are the first thing anyone
sees on the repo page, so they matter more than any other file here.

Capture at **1440×900**, light theme, at 2× if your display supports it.

| File | Route | Frame it on |
|---|---|---|
| `home.png` | `/` | The hero — "Real games. Real highlights." with the video background running |
| `matches.png` | `/matches` | The match grid, showing both players' records side by side |
| `highlight.png` | `/highlights/<any-slug>` | A highlight detail page with the audio player visible |

Then delete the `<!-- Replace these... -->` comment in the root README.
